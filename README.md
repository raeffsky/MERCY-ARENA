# MERCY ARENA

MERCY ARENA — турнирная платформа для Mobile Legends: Bang Bang и других киберспортивных дисциплин.

## Brand assets
- `public/assets/brand/mercy-mark.svg` — самостоятельная эмблема M, векторная версия для интерфейса.

## Current state
Репозиторий инициализирован. Frontend preview, API, авторизация, база данных и игровые интеграции добавляются отдельными этапами.

## Brand palette
- Background: `#08090D`
- Primary accent: `#D7FF5E`
- Text: `#F5F6FA`
- Secondary accent: `#6D78FF`

Иконки интерфейса проекта используем через Iconify.
